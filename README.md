# HR Analytics Dashboard \| Power BI

An interactive **HR Analytics Dashboard** built using Microsoft Power BI
to analyze employee demographics, workforce distribution, employee
performance, attrition and recruitment trends. The dashboard provides
HR teams with insights into workforce composition, employee retention
and recruitment patterns to support data-driven decision-making.

## Project Overview

The objective of this project is to analyze employee data to understand
workforce distribution, examine employee demographics and performance,
identify attrition patterns, compare termination rates across
departments and review recruitment sources.

The dashboard provides a **high-level workforce overview**, a **detailed
employee analysis**, and an **attrition and recruitment analysis**
through three interactive report pages.

## Dataset Used

-   **Dataset:** 
-   <a href="https://github.com/Akku017/HR-Analytics-Dashboard/blob/main/HRData.csv">HRData</a>
-   **Total Employees:** 311
-   **Source:** HR employee dataset provided for this project

The dataset includes employee demographics, department and job
information, employment status, termination details, performance
ratings, satisfaction and engagement metrics and recruitment
information.
